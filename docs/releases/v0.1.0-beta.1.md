# 桌面笔记 v0.1.0-beta.1

桌面笔记 v0.1.0-beta.1 是面向 Windows、本地优先的日历笔记应用首个公开 Beta。它是 Preview 版本，不是稳定版 1.0。

## 主要内容

- 中文界面和中文日期显示
- 按日历日期组织笔记并进行富文本编辑
- 删除不再需要的笔记
- 可左右拖动日历与笔记区域之间的分界线
- 兼容粘贴包含行内代码样式的 ChatGPT 富文本
- 标签、置顶、最近笔记和本地全文搜索
- 加密图片资源
- 快速笔记
- 自动加密备份
- 收起、标准和展开三种窗口状态
- 使用 SQLCipher 加密的本地数据库，可离线使用

数据库密钥材料由 Windows DPAPI CurrentUser 范围保护。它用于保护文档边界内的静态数据，但不会在已解锁的 Windows 会话内增加独立登录验证。

## Windows 支持

- 主要平台：Windows 11 x64
- 已测试兼容：Windows 10 22H2 x64

便携版可执行文件需要 Microsoft Edge WebView2 Runtime 和 Microsoft Visual C++ 2015-2022 Redistributable（x64）。Beta 可执行文件未签名，Windows 可能显示“未知发布者”提示。

## 已知验证缺口

以下物理硬件场景尚未完成资格验证，它们是验证缺口，不代表已知产品故障：

- 使用真实电池供电设备时的 Windows 节电模式
- 真实双显示器混合 DPI 和负坐标布局
- 真实显示器断开与重新连接

## 反馈

请使用 GitHub Issues 报告不含敏感信息的问题。报告可包含桌面笔记版本、Windows 版本、设备类型、显示器布局与缩放、准确步骤和观察结果。

不要上传真实笔记数据库、DataRoot、备份、加密密钥、密码、令牌、剪贴板内容或个人截图。安全问题应在仓库启用后使用私密 GitHub Security Advisory 报告。
